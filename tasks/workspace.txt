Kroki dla Apache Chemistry CMIS Workbench (wersja 1.1.0, wymaga Javy):
1. Pobranie
- chemistry-opencmis-workbench-1.1.0-bin.zip ze strony Apache Chemistry (archiwum wydań OpenCMIS). https://archive.apache.org/dist/chemistry/opencmis/1.1.0/
- Rozpakuj i uruchom workbench.bat (Windows).
2. Okno logowania (zakładka „Connection”)
Wybierz ręcznie wiązanie Browser, bo jest sprawdzone curl-em:
- Binding: Browser
- Browser URL: http://127.0.0.1:8080/mercury-ws-app/browser
- Authentication: Standard
- Username / Password: admin / admin (dane testowe dev)
- Compression / Cookies: bez zmian.
Kliknij Load Repositories. Powinno pojawić się repozytorium documents. Zaznacz je i kliknij Connect.
3. Wiązanie Atom (opcjonalnie)
- Binding: AtomPub, ATOM Pub URL: http://127.0.0.1:8080/mercury-ws-app/atom11 (albo /atom dla CMIS 1.0).
- Pozostałe pola bez zmian.

```cmd
netsh int ipv4 show excludedportrange protocol=tcp
```

```cmd
netsh int ip reset
netsh winsock reset
```

## Porządki z bazą danych na kubernetes:

```bash
P=postgres-db-7bcd7778f7-j8fk8
N=mercury-cluster
```

- *0. Sprawdź nazwy baz (zakładam użytkownika postgres; jeśli odmówi, zobacz env poda)*
```bash
kubectl exec -n $N $P -- psql -U postgres -c '\l'
```

- *1. Przed usunięciem obejrzyj wiersze*
```bash
kubectl exec -n $N $P -- psql -U postgres -d mercury-db   -c "select * from igo_da_license_keys"
kubectl exec -n $N $P -- psql -U postgres -d mercury-ldap -c "select * from mrc_ldap_license_keys"
```

- *2. Usuń wiersze testowe*
```bash
kubectl exec -n $N $P -- psql -U postgres -d mercury-db   -c "delete from igo_da_license_keys where id='61a7d938-e3f1-42a9-bf4f-e457af38adde'"
kubectl exec -n $N $P -- psql -U postgres -d mercury-ldap -c "delete from mrc_ldap_license_keys where id in ('6bb44a31-c1b3-48d3-9102-ffbb1afe4c3b','8129f2e0-0478-4c20-b6ea-d9f883c7c681')"
```
