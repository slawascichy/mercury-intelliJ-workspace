# Obsługa zadań

* Problem z uruchomieniem Active MQ
* Sprawdź, co dokładnie blokuje port (np. port 61616)
```cmd
netsh int ipv4 show excludedportrange protocol=tcp
```
* Najskuteczniejszym lekarstwem na "widmowe" rezerwacje portów na Windowsie jest zresetowanie IP oraz szybki restart komputera. Wykonaj w konsoli Administratora:
```cmd
netsh int ip reset
netsh winsock reset
```
